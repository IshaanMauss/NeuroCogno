Place the production logo in this folder as:

logo.png

Recommended export: transparent PNG, at least 256px wide. Square and horizontal logos are both supported.

SEO/media note:

- `/logo.png` is used by the browser favicon, Apple touch icon, Open Graph image, Twitter image, and schema logo.
- Keep the file name exactly `logo.png` unless the SEO tags are updated too.
- For best quality, use a transparent PNG with clean edges and no pasted background block.
- For production social sharing, add a separate 1200x630 image later, ideally `og-image.jpg`, and update the SEO tags to use it.
